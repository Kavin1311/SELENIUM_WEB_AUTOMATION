# SELENIUM WEB AUTOMATION

A hands-on web automation testing project using Python and Selenium WebDriver.

## Project Overview

This project demonstrates web application automation testing using Python and Selenium WebDriver. It focuses on automating browser interactions and validating webpage elements through practical test scenarios.

## Objectives

* Learn browser automation using Selenium WebDriver.
* Identify web elements using different locators.
* Validate page titles and URLs.
* Interact with forms and dropdowns.
* Inspect and validate web tables.
* Understand XPath relationships such as parent and ancestor.
* Practice browser navigation and element interaction.

## Technologies Used

* Python
* Selenium WebDriver
* Google Chrome
* Visual Studio Code
* Git and GitHub

## Testing Scope

The project covers the following scenarios:

1. Page title validation
2. URL validation
3. Web element visibility
4. Form interaction and submission
5. Dropdown selection
6. Web table inspection
7. XPath parent and ancestor relationships
8. Browser navigation

## Key Concepts

### Selenium WebDriver

Selenium WebDriver allows Python programs to control a web browser and interact with web applications.

### Element Locators

Locators such as ID, Name, Class Name, CSS Selector, and XPath help identify elements on a webpage.

### XPath Relationships

XPath supports locating elements based on their relationships with other elements, including parent and ancestor.

### Waits and Synchronization

Waits help automation scripts coordinate with webpage loading and dynamic elements.

### Validation

Validation compares actual webpage behaviour with expected results to identify whether a test condition is satisfied.

## Execution

Each test scenario will be organized as an individual Python script and executed separately.

## Current Limitations

* Test cases are executed as individual Python scripts.
* Pytest is not currently used.
* Test coverage depends on the implemented scenarios.
* Changes to the target website may require locator updates.
